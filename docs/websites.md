# Websites to Learn

Platforms for learning .NET and sharpening your problem-solving skills. Each entry notes how it helps a C#/.NET developer.

## Course Platforms

1. [Pluralsight](https://www.pluralsight.com/) — Deep .NET catalog with skill assessments and learning paths; home to many Microsoft MVP authors.

2. [Udemy](https://www.udemy.com/courses/search/?src=ukw&q=C%23) — Huge marketplace of affordable, project-based C# and .NET courses.

3. [Coursera](https://www.coursera.org/search?query=C%23&) — University and industry courses, including C# and .NET specializations with certificates.

4. [Udacity](https://www.udacity.com/) — Project-focused nanodegrees in programming and cloud development.

5. [edX](https://www.edx.org/) — University-led courses, including Microsoft's own C# and Azure programs.

6. [freeCodeCamp](https://www.freecodecamp.org/) — Free, hands-on curriculum with a growing set of C#/.NET tutorials and certifications.

7. [Microsoft Learn](https://learn.microsoft.com/en-us/training/) — Free, official .NET and C# learning paths straight from Microsoft.

---

## Problem Solving

All of the sites below support solving challenges in **C#**, making them ideal for sharpening .NET fundamentals and preparing for interviews.

1. [LeetCode](https://leetcode.com/) — The go-to site for interview-style algorithm problems; full C# support.

2. [HackerRank](https://www.hackerrank.com/) — Skill-based challenges and certifications with a dedicated C# track.

3. [Codeforces](https://codeforces.com/) — Competitive-programming contests with C# submissions accepted.

4. [CodeChef](https://www.codechef.com/) — Monthly contests and a large practice problem set supporting C#.

5. [Exercism](https://exercism.io/) — Free C# track with mentored solutions and code review.

6. [Codewars](https://www.codewars.com/) — Community "kata" challenges to practice idiomatic C#.

7. [Project Euler](https://projecteuler.net/) — Math-heavy programming problems great for practising LINQ and algorithms in C#.

8. [CodeSignal](https://codesignal.com/) — Interview practice and assessments with C# support.

9. [NeetCode](https://neetcode.io/) — Curated, pattern-based roadmap of the most important interview problems.

10. [CodinGame](https://www.codingame.com/start) — Learn by solving game-based puzzles in C#.

11. [SPOJ](https://www.spoj.com/) — Classic online judge with thousands of problems and C# support.

12. [CodeAbbey](https://www.codeabbey.com/) — Beginner-friendly problems for building a programming foundation.

13. [Code Golf](https://code.golf/) — Solve problems in the fewest characters possible, C# included.

14. [Coding Ninjas](https://www.codingninjas.com/) — Structured courses and practice problems for interview preparation.
