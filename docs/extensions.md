# Helpful Extensions for Visual Studio & VS Code

Productivity extensions that make .NET development faster and more pleasant. Grouped by editor.

## Visual Studio

| Extension | Description |
| --- | --- |
| [IntelliCode](https://marketplace.visualstudio.com/items?itemName=VisualStudioExptTeam.VSIntelliCode) | AI-assisted IntelliSense that ranks completions by context. |
| [ReSharper](https://www.jetbrains.com/resharper/) | JetBrains code analysis, refactoring, and navigation for C#. |
| [CodeMaid](https://marketplace.visualstudio.com/items?itemName=SteveCadwallader.CodeMaidVS2022) | Cleans up and organizes C# and VB code. |
| [Visual Studio Spell Checker](https://marketplace.visualstudio.com/items?itemName=EWoodruff.VisualStudioSpellCheckerVS2022andLater) | Spell checks comments, strings, and plain text. |
| [SlowCheetah](https://marketplace.visualstudio.com/items?itemName=vscps.SlowCheetah-XMLTransforms) | Previews and applies XML/JSON config transforms. |
| [Image Optimizer](https://marketplace.visualstudio.com/items?itemName=MadsKristensen.ImageOptimizer64bit) | Losslessly optimizes PNG, JPG, GIF, and SVG images. |
| [VSColorOutput](https://marketplace.visualstudio.com/items?itemName=MikeWard-AnnArbor.VSColorOutput64) | Colorizes the build and debug output window. |
