# Contributing

Thanks for helping make **Awesome .NET Resources** better! Contributions of new resources, fixes, and improvements are welcome.

## How to add a resource

1. **Fork** this repository and create a branch.
2. Find the right file under [`docs/`](./docs) (e.g. `libraries.md`, `courses.md`).
3. Add your entry following the existing format in that file.
4. Open a Pull Request using the template.

## Guidelines

- **One resource per entry.** Keep it relevant to .NET / C# developers.
- **No dead links.** The link checker runs automatically on every PR — make sure your link works.
- **Quality over quantity.** The resource should be genuinely useful, maintained, and not spam.
- **Alphabetical / logical order.** Place new entries where they fit the existing grouping.
- **Describe it.** Add a short, neutral one-line description — no marketing language.
- **Disclose affiliations.** Mark affiliate links with an asterisk (`*`) and disclose any personal relationship to the resource.

## Tag legend

Where a list uses tags, please use these consistently:

| Tag | Meaning |
| --- | --- |

| 🟡 | Intermediate |
| 🔴 | Advanced |
| 💲 | Paid |

## What gets rejected

- Broken, paywalled-without-disclosure, or self-promotional spam links.
- Duplicates of existing entries.
- Resources unrelated to the .NET ecosystem.
